# Andiswa Phewa Portfolio

Multi-page professional portfolio website.

## Pages

- Home
- About
- Teaching
- Projects
- Data & Analytics
- Research
- Experience
- Contact

## Structure

- `assets/css/styles.css` for styling
- `assets/js/main.js` for responsive navigation, reveal animations, project filtering, project details, contact form behaviour and back-to-top behaviour
- `assets/images/` for portfolio images
- `assets/docs/` for the downloadable CV

Open `index.html` in a browser or deploy the folder to any static host.
